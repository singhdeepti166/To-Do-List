# To-Do List

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by All, Active, and Done.
- Clear all completed tasks.
- Display remaining task count.
- Save tasks using Browser LocalStorage.
- Tasks remain saved after refreshing the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start adding your tasks!

## How Data Is Stored

All tasks are maintained in a JavaScript array. The application uses `JSON.stringify()` to save the array in LocalStorage and `JSON.parse()` to retrieve it when the page loads.
